# 📝 Projeto: Meu portifólio 

## Autor: Luan S. Marin

## Linguagem: HTML5 com CSS e Bootstrap

Sobre: Este projeto é o meu portifólio profissional em forma de site 
com descrição, dados profissionais e links para outros projetos 
desenvolvidos.

Site:

Explicação: O projeto foi feito em HTML com assistencia das ferramntas CSS
e Bootstrap contendo varias seções como a barra de navegação que fica no topo
da página, menu offcanvas que aparece no canto e leva para diferentes partes 
do site, carrossel com 3 slide e informações, perfil com informações basicas
sobre formação e programas que utilizo, seção de projetos que redireciona a
minha página de projetos do Github, Contatos e a linha do rodapé 
da página.

Novo recurso adcionado: O novo recurso que adcionei foi o menu offcanvas que
contem 3 botões que servem para direcionar a diferentes partes da página. Este
recurso foi implementado como a classe offcanvas, três botões diferentes e um
script para auxiliar o funcioanmento fechando o offcanvas quando ele chega na
parte solicitada.
